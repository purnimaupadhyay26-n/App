# MAIRA — New Android Studio Project

Native Kotlin + Jetpack Compose UI prototype. Open this folder in Android Studio, use JDK 17, sync Gradle, and run on an emulator.

## Updated UI
- Warm pink, peach, butter-yellow and white palette
- Larger readable typography, consistent cards and spacing
- Mother dashboard with pregnancy journey, records, reminders, quick actions and care assistant preview
- ASHA dashboard with at-a-glance mother/newborn/visit/due-date stats and 2-column quick tools
- Driver console with vehicle status, trip metrics, navigation/vehicle-check actions and clear no-trip state
- Hospital referral queue preview
- Role-specific demo login pages

## Scope
UI/demo interactions only. Demo metrics are synthetic. Authentication, OTP delivery, secure persistence, backend, live GPS, actual hospital readiness and ambulance integration are not implemented. Do not use real patient data.
